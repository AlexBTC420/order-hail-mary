# Drafts

Work-in-progress documents that are **not yet canon**.

## Rules

1. Open an issue titled `Proposal: Document N — <title>` before or alongside a draft.
2. Place drafts here as `docs/drafts/NN-short-title.md`.
3. Drafts must remain infrastructure-first (no token sales, no return promises).
4. Promotion to canon requires:
   - community discussion on the issue,
   - a PR that moves the file to `docs/` with a number,
   - an update to the README canon table,
   - a `CHANGELOG.md` entry.

See [CONTRIBUTING.md](../../CONTRIBUTING.md) for full process and editorial gates.
